1. Retrieve a list of all Student Names and the Courses they have enrolled
in.

 select u.name ,c.course_name from users u join enrollment e on u.user_id = e.user_id join course c on e.course_id = c.course_id;


2. Display the Names and Cities of students who have a 'Completed'
payment status.

 select u.name , u.city from users u join payment p on u.user_id = p.user_id where payment_status = 'completed';

3. List every Course Name along with the Instructor assigned to teach it.

 select c.course_name , i.name from course c join course_instructor ci on ci.course_id = c.course_id join instructors i on i.instructor_id = ci.instructor_id;

4. Find the names of students from 'Jaipur' who enrolled specifically in the
'SQL' course.

SELECT 
    u.name
FROM users u
JOIN enrollment e 
    ON u.user_id = e.user_id
JOIN course c 
    ON c.course_id = e.course_id
WHERE u.city = 'Jaipur'
AND c.course_name = 'SQL Basics';

5. List all users whose Payment Amount matches the original Price of the
course.

SELECT 
    u.name,
    c.course_name,
    p.amount,
    c.price
FROM users u
JOIN payment p 
    ON u.user_id = p.user_id
JOIN course c 
    ON p.course_id = c.course_id
WHERE p.amount = c.price;

Set 3: Complex Logic (5-6 Tables & Filters)

1. Master Audit Report: Write a query to display Student Name, Course Name, Instructor Name, Payment Amount, and Payment Status all in one

row.
SELECT 
    u.name AS student_name,
    c.course_name,
    i.name AS instructor_name,
    p.amount,
    p.payment_status
FROM users u
JOIN enrollment e 
    ON u.user_id = e.user_id
JOIN course c 
    ON e.course_id = c.course_id
JOIN payment p 
    ON u.user_id = p.user_id 
    AND c.course_id = p.course_id
JOIN course_instructor ci 
    ON c.course_id = ci.course_id
JOIN instructors i 
    ON ci.instructor_id = i.instructor_id;
